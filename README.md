# Власні анотації та Рефлексія в Java

Цей проєкт демонструє створення власних анотацій, їх застосування до методів класу, а також зчитування метаданих під час виконання програми (Runtime) за допомогою Java Reflection API.

## 🚀 Опис функціоналу

1. **Власні анотації:**
    * `@MethodInfo` — містить назву методу, тип поверненого значення та опис його призначення.
    * `@Author` — містить інформацію про розробника методу (ім'я та прізвище).
2. **Утилітарний клас `ArrayUtils`:**
    * Містить статичні методи для обробки масивів цілих чисел.
    * Позначений створеними анотаціями.
3. **Рефлексія (Main):**
    * Демонструє роботу алгоритмів.
    * Динамічно зчитує та виводить у консоль метадані з анотацій для кожного методу.

## 🛠️ Архітектурні покращення та Best Practices

В процесі рефакторингу код було оптимізовано під стандарти Production-розробки:
* **Utility Class Pattern:** Клас `ArrayUtils` містить виключно `static` методи і не має стану. Створення його екземплярів заблоковано за допомогою приватного конструктора, який викидає `UnsupportedOperationException`.
* **In-Place Оптимізація:** Метод `reverseArray` реалізовано за допомогою алгоритму двох вказівників. Це дозволило розвертати масив без використання додаткової пам'яті — складність за пам'яттю знижено з **O(N)** до **O(1)**.
* **Edge Cases:** Додано захисні перевірки на `null` та порожні масиви (`length <= 1`), що запобігає виникненню критичних помилок під час виконання.

## 📁 Структура проєкту

```text
src/app/
│
├── Author.java       # Анотація для збереження інформації про автора
├── MethodInfo.java   # Анотація для опису характеристик методу
├── ArrayUtils.java   # Утилітарний клас із методами обробки масивів
└── Main.java         # Точка входу, демонстрація роботи та рефлексії
```

## 💻 Інструкція із запуску (CLI)

Якщо ви компілюєте проєкт через термінал без використання IDE, виконайте такі команди:

1. Скомпілюйте всі файли у папку `out`:
   ```bash
   javac -d out src/app/*.java
   ```

2. Запустіть програму:
   ```bash
   java -cp out app.Main
   ```
